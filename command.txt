#Python Virtual Env Create:

#Windows
1. Create Env: python -m venv .venv
2. Activate Env  Windows: .venv/Scripts/activate
3. Dependencies Install: pip install -r requirements.txt


#Linux
1. Create Env: python3 -m venv .venv
2. Activate Env  Linux: source .venv/bin/activate
3. Dependencies Install: pip install -r requirements.txt
